# FileZilla — Free Offline Installer

![Category](https://img.shields.io/badge/FTP_Client-blue?style=flat-square)

## About

FileZilla is a free, open-source FTP, FTPS, and SFTP client for Windows, macOS, and Linux. Transfer files between local and remote systems with a dual-pane interface, queue large file transfers, resume interrupted transfers, and manage bookmarks for frequently accessed servers. FileZilla remains the most widely used free FTP client due to its reliability and broad protocol support.

## Common Problems & Limitations

- **Bundled Software Risk** — Windows installer historically bundled adware; download from official site only
- **FTP Security** — FTP protocol transmits credentials in plain text; use SFTP when possible
- **Interface Dated** — Visual design reflects the software's older origins
- **Synchronization** — Manual file management only; no automated sync capabilities
